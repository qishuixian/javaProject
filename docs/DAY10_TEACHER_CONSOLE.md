# Day 10：入门综合练习——控制台教师管理

## 1. 今日目标

把 Day1～Day9 的变量、分支、循环、数组、方法、对象、接口和常量串起来，做一个可以键盘操作的程序：新增教师、按 ID 查询、修改姓名、退出。

这是内存版教学练习，容量为 3，退出后数据消失。不连接业务数据库，不需要启动 Spring Boot。

## 2. 打开与运行

在 IDEA 打开 [Day10TeacherConsole.java](../java-basics/src/Day10TeacherConsole.java)，点击 main 左侧绿色三角。点击下方 Run 控制台，在提示后输入内容，每输入一项按一次回车。

依赖文件都在同一个 src 目录：

不修改前几课文件。没有新增运行脚本，IDEA 自动管理编译产物。

## 4. 程序如何执行

```text
main 创建目录和键盘读取器
  → 循环读取操作
  → 读取并解析 ID
  → 查询，或继续读取姓名并新增/改名
  → 打印成功结果或错误原因
  → 回到菜单
```

新增时：控制台 → directory.add → Teacher 构造校验 → ID 判重 → 容量校验 → 存入数组。

查询时：控制台 → printTeacher(TeacherRepository, id) → 实际目录的 findById → Teacher 或 null。

改名时：控制台 → directory.rename → 查找对象 → Teacher.rename 校验后赋值。

## 5. 逐段理解新写法

### 读取键盘

```java
Scanner scanner = new Scanner(System.in);
```

Scanner 是 Java 标准库的输入工具，System.in 是标准输入。先通过 import 引入类名，再创建对象。

```java
scanner.hasNextLine(); // 是否还有一行可读
scanner.nextLine();    // 读取一整行，不包含末尾换行符
```

控制台会等待你输入。readLine 方法统一读取整行并 trim 去掉两端空白，不混用 nextInt 和 nextLine，避免残留换行影响下一次输入。

没有下一行时返回 null，代表输入结束；空行则是空字符串，不是 null。主循环遇到输入结束会退出，输入中途结束也不会保存不完整的教师。

### 字符串变成数字

```java
long id = Long.parseLong(idText);
```

键盘读到的 `"10001"` 是字符串，parseLong 将它转成 long。输入 abc、小数或超出 long 范围的整数会抛出 NumberFormatException。

这里 catch 先捕获 NumberFormatException，再捕获 IllegalArgumentException，因为前者是后者的子类。较具体的异常必须先处理。暂时理解“输入错了，显示提示并继续”，Day13 再系统学习异常体系。

### 循环控制

- while (true)：不断显示菜单，直到显式退出。
- break：退出循环，最后打印“已退出”。
- continue：结束本轮，回到下一次操作输入。
- "2".equals(command)：用 Day9 学过的字符串内容比较，不用 ==。

输入 0 仅在菜单处表示退出；姓名输入中的 0 是姓名文本，ID 输入中的 0 则不合法。

## 6. 数组容量与当前人数不是一回事

```java
private final Teacher[] teachers;
private int size;
```

teachers.length 是最多能放多少教师，size 是已经放入多少教师。new Teacher[3] 初始包含三个 null 元素，size 初始为 0。

```java
teachers[size] = teacher;
size++;
```

先放到下一个空位置，再增加人数。遍历只读下标 0 到 size - 1，避免访问尚未使用的 null 槽位。

final 数组引用不能重新赋值，但数组元素仍可以修改，正好复习 Day8。检查目录已满后再写入，可以避免数组越界。

## 7. 为什么先校验再保存

add 在真正写入前完成：ID/姓名合法性、重复 ID、容量检查。失败后数组和 size 不变。

rename 先查找教师，再调用 Teacher.rename；姓名校验不通过时，原姓名不变。已有教师改名不需要额外容量，满目录也可以改名。

本课使用 long ID 判重，直接 `==` 比较数值，不要求为 Teacher 重写 equals。Day9 的对象相等规则只在需要比较对象或集合按对象去重时发挥作用，不必为了用知识点而强行套用。

目录查询返回实际 Teacher 引用，不是副本；调用方仍可通过其公开方法改名，但不能改 private final ID。这是当前简单模型的边界，不是数据库快照或完整权限系统。

## 8. 手动验收场景

每个场景可单独重新运行程序，也可以按表顺序执行：

| 场景 | 操作 | 应看到的结果 |
|---|---|---|
| 正常新增 | 新增 10001 / 张老师 | 当前人数 1 |
| 重复 ID | 再新增 10001 / 王老师 | 教师 ID 已存在；查询仍为张老师 |
| 空姓名 | 新增 10002，姓名直接回车 | 姓名不能为空；10002 不存在 |
| 正常改名 | 将 10001 改为李老师 | 改名成功；查询为李老师 |
| 非法改名 | 将 10001 改为空白 | 拒绝修改；原姓名仍为李老师 |
| 不存在 | 查询或改名 99999 | 未找到教师或教师不存在 |
| 非整数 ID | 查询时输入 abc | ID 必须是 long 范围内的整数；回到菜单 |
| 非正数 ID | 输入 0 或 -1 | ID 必须大于 0 |
| 满容量 | 保存三个不同 ID 后再新增第四位 | 目录已满；已有数据可继续查询和改名 |
| 未知操作 | 菜单输入 9 | 提示可用操作，继续等待 |
| 退出 | 菜单输入 0 | 已退出 |

所有演示数据只用于学习。若先输入非法 ID，程序直接回菜单，不会继续等待姓名，应按新提示输入。

## 9. 与目标项目的联系

aic-teaching-service 的教师管理同样有接收输入、校验、查询和修改的职责，但通过 HTTP Controller、Service 和 Mapper 等组件协作。本课用控制台替代 HTTP，用数组替代数据库，先把业务流程走通；不表示已经具备事务、持久化或权限控制。
